# Jewellery-Website
JewelryE-CommerceWebsite– Developed a sleek, user-friendly platform showcasing exquisite  jewelry collections with seamless navigation and engaging UI/UX.
<br><br>
The Online Jewellery Shop is a website that enables customers to browse and buy jewellery online, categorizing products like Gold, Silver, and Diamond. It aims to provide an online shopping solution, automating basic operations and providing admin access to vendors and admins, solving issues with time-consuming manual processes and report generation.

Skills: Cascading Style Sheets (CSS), HTML , +4 skills
